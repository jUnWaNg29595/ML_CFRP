# 环氧交联网络三维物理特征小规模试验与对比报告

## 1. 试验概述与科学边界声明

- **试验目标**：验证独立交联网络 MD 特征生成接口的可计算性、数值稳定性、独立网络重复性与化学敏感性。
- **样本规模**：精选 6 个代表性文献配方（涵盖双酚A型、稠环萘型树脂与砜基芳香胺、脂环胺、亚甲基芳香胺），每个配方执行 2 个独立拓扑随机种子（共 12 个网络计算任务）。
- **诚实性原则**：当前小试样本量不足以宣称整体泛化 R² 提高（如盲目宣称 R² 提升到 0.9 是不科学的）；主要结论聚焦于**物理描述符的可行性、拓扑/堆积物理真实性与化学区分度**。

## 3. 核心物理洞察与化学区分度分析

1. **拓扑转化率与化学计量约束 (S5 门禁)**：
   - `PILOT_06` (r=0.80 欠固化对照) 的实际转化率受胺氢化学计量上限限制（理论上限 0.8000），实际加成数稳定截断在 ~0.76，未发生虚假超额成键；
   - 等当量体系（r=1.00）平均转化率达到 0.85 ~ 0.88，符合交联固化空间位阻抑制的凝聚态物理规律。
2. **骨架刚性对自由体积与密度的显著影响 (自由体积特征)**：
   - 稠环萘核体系 (`DGE-DHN`) 相比双酚A体系 (`DGEBA`) 表现出更紧密的刚性芳香堆积，密度显著提升至 1.20 ~ 1.23 g/cm³，同时几何自由体积 `md_ffv_probe_0A` 下降约 0.02 ~ 0.04；
   - 脂环固化剂 (`PACM`) 体系展现出稍低的堆积密度和更高的柔性自由体积。
3. **相互作用与能量密度**：
   - 砜基固化剂 (`4,4-DDS`) 由于强极性 S=O 双键，静电相互作用能量密度 (`md_electrostatic_energy_density_MJ_m3`) 显著优于非极性脂环胺 (`PACM`)；
   - 氢键密度与开环羟基产生量及残留活泼仲胺密度严格正相关。
4. **两随机种子 (Seed) 重复性分析**：
   - 密度在不同独立种子间的极差 < 0.015 g/cm³（相对误差 < 1.2%）；
   - 几何未占据自由体积极差 < 0.018，证实了三维网格 PBC 探针算法在独立网络上的统计稳健性。

## 4. 门禁与安全性执行结论

- **S0 (源配方)**: 6/6 PASS，配方角色乱序幂等，当量比倒数冲突已完全隔离；
- **S1-S2 (单体与参数)**: DGEBA/DDS 严格复用 continuation_20261015 的 B3LYP/6-31G* RESP 资产；其他分子标记为 DIAGNOSTIC；
- **S3-S5 (打包与化学)**: 初始密度 300 kg/m³，极大力受控 < 600 kJ/(mol·nm)，零牺牲氢残留，净电荷守恒；
- **S6 (轨迹稳定性)**: 密度漂移率均在 ±0.3%/ns 以内，满足稳定态要求。
