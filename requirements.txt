## 安装指南

### 最小安装 (仅核心功能)
```bash
pip install pandas numpy scikit-learn xgboost rdkit streamlit plotly shap optuna
```

### 推荐安装 (包含深度学习)
```bash
pip install -r requirements.txt

# PyTorch with CUDA (根据你的CUDA版本选择)
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
```

### 完整安装 (包含所有可选功能)
```bash
pip install -r requirements-full.txt
```

## 版本兼容性

### Python版本
- 推荐: Python 3.10.x
- 支持: Python 3.9 - 3.11
- 不支持: Python 3.12+ (部分依赖不兼容)

### CUDA版本 (GPU训练)
- CUDA 11.8: 推荐
- CUDA 12.1: 支持
- CUDA 12.4: 部分支持

### 操作系统
- Windows 10/11: ✅ 完全支持
- Linux (Ubuntu 20.04+): ✅ 完全支持
- macOS: ⚠️ 部分功能受限 (无CUDA,部分RDKit功能)

## 常见安装问题

### Q1: RDKit安装失败
```bash
# 使用conda安装
conda install -c conda-forge rdkit

# 或使用mamba
mamba install rdkit
```

### Q2: PyTorch Geometric安装失败
```bash
# 确保PyTorch版本匹配
pip install torch==2.1.0

# 安装PyG
pip install torch-geometric
pip install torch-scatter torch-sparse -f https://data.pyg.org/whl/torch-2.1.0+cu118.html
```

### Q3: TensorFlow版本冲突
```bash
# DECIMER需要TensorFlow 2.x
pip install tensorflow==2.15.0

# 如果与PyTorch冲突,考虑使用不同环境
conda create -n decimer_env tensorflow==2.15.0
```

### Q4: SHAP安装慢
```bash
# 使用预编译wheel
pip install shap --prefer-binary
```


## 虚拟环境建议

### Conda环境
```bash
conda create -n cfrp_env python=3.10
conda activate cfrp_env
pip install -r requirements.txt
```

### venv环境
```bash
python -m venv cfrp_venv
source cfrp_venv/bin/activate  # Linux/macOS
cfrp_venv\Scripts\activate      # Windows
pip install -r requirements.txt
```

## 内存需求

### 最小内存
- 训练: 4GB RAM
- 预测: 2GB RAM
- 虚拟筛选: 8GB RAM (取决于候选数量)

### 推荐内存
- 训练深度学习模型: 16GB+ RAM
- 大规模虚拟筛选: 32GB+ RAM
- 图像转SMILES: 8GB+ RAM

## GPU需求

### NVIDIA GPU
- 计算能力: 7.0+ (推荐)
- 显存: 6GB+ (训练), 8GB+ (虚拟筛选)
- CUDA: 11.8或12.1

### AMD GPU (ROCm)
- 支持: 部分支持
- 需要ROCm 5.4+
- 参考: https://rocm.docs.amd.com/
