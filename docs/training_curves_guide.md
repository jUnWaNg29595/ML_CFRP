# 训练曲线使用指南

## 功能概述

训练曲线可视化展示了模型在训练过程中的性能变化，帮助你：
- 判断模型是否收敛
- 识别过拟合/欠拟合
- 确定最佳训练轮数
- 评估早停机制效果

## 显示的指标

### 1. R² (决定系数)
- **范围**: 0-1（越接近1越好）
- **含义**: 模型解释的方差比例
- **用途**: 最直观的拟合效果指标

**示例曲线**:
```
R² 曲线
1.0 ┤                    ╭─────────
0.8 ┤              ╭─────╯
0.6 ┤        ╭─────╯
0.4 ┤   ╭────╯
0.2 ┤╭──╯
0.0 ┼────────────────────────────
    0   50  100  150  200  250
         Epoch/Iteration
```

**判断标准**:
- Train R² > 0.9, Test R² > 0.8: 优秀
- Train R² > 0.8, Test R² > 0.7: 良好
- Train R² >> Test R²: 过拟合
- Train R² ≈ Test R² 但都很低: 欠拟合

### 2. MAE (平均绝对误差)
- **范围**: ≥0（越小越好）
- **含义**: 预测值与真实值的平均偏差
- **用途**: 与目标变量同单位，易于理解

**示例曲线**:
```
MAE 曲线
50 ┤╮
40 ┤ ╰╮
30 ┤   ╰╮
20 ┤     ╰─╮
10 ┤        ╰────────────
 0 ┼────────────────────────────
    0   50  100  150  200  250
         Epoch/Iteration
```

**判断标准**:
- MAE持续下降: 模型在学习
- MAE趋于平稳: 模型收敛
- Test MAE上升: 开始过拟合

### 3. MSE (均方误差)
- **范围**: ≥0（越小越好）
- **含义**: 预测误差的平方平均
- **用途**: 对大误差更敏感

## 过拟合识别

### 典型过拟合曲线
```
R² 曲线
1.0 ┤        Train ──────────────
0.9 ┤      ╱
0.8 ┤    ╱
0.7 ┤  ╱    Test ╭───────╮
0.6 ┤╱          ╱         ╲
0.5 ┼─────────╱            ╲────
    0   50  100  150  200  250
         Epoch/Iteration
         ↑
      开始过拟合
```

**特征**:
1. 训练集R²持续上升
2. 测试集R²先升后降
3. 训练集和测试集差距越来越大

**解决方案**:
- 启用早停（已默认启用）
- 增加正则化（`reg_alpha`, `reg_lambda`）
- 减少模型复杂度（`max_depth`, `n_estimators`）
- 增加训练数据

## 欠拟合识别

### 典型欠拟合曲线
```
R² 曲线
0.5 ┤    Train ────────────
0.4 ┤  ╱
0.3 ┤╱     Test ──────────
0.2 ┼────────────────────────
    0   50  100  150  200  250
         Epoch/Iteration
```

**特征**:
1. 训练集和测试集R²都很低
2. 两者差距不大
3. 曲线很快趋于平稳

**解决方案**:
- 增加模型复杂度（`max_depth`, `n_estimators`）
- 减少正则化
- 增加特征工程
- 尝试更复杂的模型

**特征**:

2. 最终趋于稳定
3. 两者差距适中（<0.1-0.15）
4. 早停在合适的位置触发

## 早停机制

### 工作原理
- 监控测试集的RMSE
- 如果连续50轮没有改善，停止训练
- 自动恢复到最佳轮数的模型

### 配置
```python
# 默认配置（已自动启用）
early_stopping_rounds = 50

# 自定义配置
params = {
    'early_stopping_rounds': 30,  # 更激进的早停
}
```

### 输出示例
```
[150]   validation_1-rmse:28.45  ← 最佳
[151]   validation_1-rmse:28.46
[152]   validation_1-rmse:28.47
...
[200]   validation_1-rmse:28.50

Stopping. Best iteration:
[150]   validation_1-rmse:28.45
```

## 常见问题

### Q1: 为什么训练集R²=1.0但测试集R²很低？
**A**: 严重过拟合。模型记住了训练数据但无法泛化。

**解决方案**:
- 减少`n_estimators`（如从10000降到500）
- 增加`min_child_weight`
- 增加`reg_alpha`和`reg_lambda`

### Q2: 为什么曲线一直在震荡？
**A**: 学习率可能太高或数据噪声大。

**解决方案**:
- 降低`learning_rate`（如从0.3降到0.1）
- 增加`subsample`和`colsample_bytree`
- 检查数据质量

### Q3: 为什么早停没有触发？
**A**: 现在已经默认启用，如果没触发可能是：
- 模型一直在改善（正常）
- 达到了最大轮数限制

### Q4: 训练集和测试集差距多大算正常？
**A**:
- R²差距 < 0.1: 优秀
- R²差距 0.1-0.15: 良好
- R²差距 > 0.2: 需要关注过拟合

## 最佳实践

1. **始终查看训练曲线** - 不要只看最终指标
2. **关注测试集曲线** - 训练集指标可能误导
3. **使用早停** - 避免过度训练（已默认启用）
4. **保存训练曲线** - 用于后续分析和报告
5. **对比不同配置** - 通过曲线选择最佳超参数

## GPU并行训练

现在支持在不同GPU上同时训练多个模型：

1. 在GPU设置中选择"GPU 0"
2. 开始第一个训练
3. 在新标签页中选择"GPU 1"
4. 开始第二个训练
5. 两个训练互不干扰，可以对比不同配置

## 导出训练曲线

训练完成后可以：
- 下载训练曲线图（PNG格式）
- 导出训练历史数据（CSV格式）
- 用于论文、报告或进一步分析
