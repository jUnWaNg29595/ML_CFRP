# TabNet 预设配置说明

## 三种预设配置对比

### ⚡ 快速训练
**适用场景**: 初步测试、快速验证、小数据集(<500样本)

**特点**:
- 训练速度最快 (~2-5分钟)
- 模型容量较小,不易过拟合
- 适合快速迭代和参数探索

**参数配置**:
- 模型大小: n_d=16, n_a=16, n_steps=3 (最小)
- 学习率: 0.005 (较高,收敛快)
- 训练轮数: 100 epochs
- 批次大小: 256

**预期性能**: R² 0.6-0.8

---

### ⭐ 推荐配置 (默认)
**适用场景**: 大多数场景、中等数据集(500-5000样本)、生产环境

**特点**:
- 平衡性能和训练时间
- 稳定性好,不易崩溃
- 适合大多数回归任务

**参数配置**:
- 模型大小: n_d=32, n_a=32, n_steps=3 (中等)
- 学习率: 0.003 (稳定)
- 训练轮数: 200 epochs
- 批次大小: 256
- 正则化: lambda_sparse=1e-3

**预期性能**: R² 0.75-0.90

**推荐理由**:
1. 经过大量测试验证
2. 训练稳定,很少出现loss=0崩溃
3. 性能和速度的最佳平衡点

---

### 🚀 高性能
**适用场景**: 追求最佳性能、大数据集(>5000样本)、复杂特征关系

**特点**:
- 模型容量最大,表达能力强
- 训练时间较长 (~15-30分钟)
- 可能需要更多数据防止过拟合

**参数配置**:
- 模型大小: n_d=64, n_a=64, n_steps=5 (最大)
- 学习率: 0.002 (较低,更稳定)
- 训练轮数: 300 epochs
- 批次大小: 512
- 正则化: lambda_sparse=5e-4 (较弱,允许更复杂模型)

**预期性能**: R² 0.85-0.95

**注意事项**:
- 需要足够的训练数据(建议>2000样本)
- 训练时间较长,需要耐心等待
- 如果数据量不足,可能过拟合(train R² >> test R²)

---

## 如何选择?

### 根据数据集大小选择:
- **< 500 样本**: 使用 ⚡ 快速训练
- **500-2000 样本**: 使用 ⭐ 推荐配置
- **> 2000 样本**: 可尝试 🚀 高性能

### 根据训练结果调整:

#### 如果 R² < 0.6 (性能不足):
1. 先尝试 🚀 高性能配置
2. 如果还不够,手动增加:
   - n_d/n_a 到 96 或 128
   - n_steps 到 7
   - max_epochs 到 500

#### 如果出现过拟合 (train R² - test R² > 0.15):
1. 增加正则化: lambda_sparse 从 1e-3 → 1e-2
2. 减小模型: n_d/n_a 从 64 → 32
3. 增加 patience (更早停止)

#### 如果训练崩溃 (loss=0):
1. 降低学习率: 0.005 → 0.002 → 0.001
2. 减小批次: batch_size 512 → 256 → 128
3. 检查数据是否有异常值

## 参数详解

### 模型架构参数:
- **n_d**: 决策层维度,控制模型容量
- **n_a**: 注意力层维度,通常与n_d相同
- **n_steps**: 决策步数,类似决策树的深度
- **gamma**: 特征重用系数,越大特征选择越稀疏

### 训练参数:
- **learning_rate**: 学习率,最关键参数!
  - 过高 → 训练崩溃(loss=0)
  - 过低 → 收敛慢,性能差
  - 推荐范围: 0.001-0.005

- **batch_size**: 批次大小
  - 越大 → 训练越稳定,但可能性能略差
  - 越小 → 更新频繁,但可能不稳定
  - 推荐: 256 (中等数据集)

- **lambda_sparse**: 稀疏正则化
  - 越大 → 特征选择越稀疏,防止过拟合
  - 越小 → 使用更多特征,模型更复杂
  - 推荐: 1e-3 到 1e-4

### 早停参数:
- **patience**: 验证集不改善多少轮后停止
  - 太小 → 可能过早停止
  - 太大 → 训练时间长,可能过拟合
  - 推荐: 20 (中等数据集)

## 常见问题

### Q: 为什么我的R²只有0.18?
A: 可能原因:
1. 学习率过高导致训练不稳定
2. 模型容量不足(n_d太小)
3. 训练轮数不够
4. 数据质量问题(噪声大、特征不相关)

**解决方案**: 先尝试 ⭐ 推荐配置,如果还不够,再试 🚀 高性能

### Q: 训练时出现loss=0怎么办?
A: 这是学习率过高导致的崩溃
1. 立即降低学习率到 0.002 或 0.001
2. 减小batch_size到 128 或 256
3. 使用 ⚡ 快速训练 或 ⭐ 推荐配置

### Q: 训练太慢怎么办?
A:
1. 使用 ⚡ 快速训练配置
2. 减少 max_epochs 到 100
3. 增大 batch_size 到 512
4. 减小 n_d/n_a 到 16 或 24

### Q: 过拟合怎么办?
A:
1. 增加 lambda_sparse 到 5e-3 或 1e-2
2. 减小模型容量 (n_d/n_a)
3. 减少 n_steps
4. 增加数据量或数据增强

## 实验建议

### 第一次使用TabNet:
1. 先用 ⚡ 快速训练 测试是否能正常运行
2. 如果正常,再用 ⭐ 推荐配置 获得更好性能
3. 如果性能不够,最后尝试 🚀 高性能

### 参数调优顺序:
1. **学习率** (最重要!) → 0.005, 0.003, 0.002, 0.001
2. **模型大小** (n_d/n_a) → 16, 32, 64, 96
3. **正则化** (lambda_sparse) → 1e-2, 1e-3, 1e-4
4. **训练轮数** (max_epochs) → 100, 200, 300

### 性能基准:
- R² > 0.8: 优秀
- R² 0.6-0.8: 良好
- R² 0.4-0.6: 一般,需要调优
- R² < 0.4: 较差,检查数据或换模型

---

**提示**: 如果三个预设都无法达到满意效果,可能需要:
1. 检查数据质量和特征工程
2. 尝试其他模型 (XGBoost, LightGBM, CatBoost)
3. 使用AutoML自动调优
