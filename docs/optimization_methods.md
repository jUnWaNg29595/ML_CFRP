# 超参数优化方法说明

## 可用的优化算法

### 1. TPE (Tree-structured Parzen Estimator) - 贝叶斯优化 ⭐推荐
- **类型**: 贝叶斯优化
- **特点**:
  - 基于历史试验结果智能选择下一组参数
  - 平衡探索（exploration）和利用（exploitation）
  - 适合大多数场景，是默认推荐方法
- **适用场景**: 通用，特别适合中等规模搜索空间（10-100个trials）
- **优点**: 收敛快，效果稳定
- **缺点**: 对于极高维参数空间可能不如GP

### 2. Gaussian Process (高斯过程) - 贝叶斯优化
- **类型**: 贝叶斯优化
- **特点**:
  - 使用高斯过程建模目标函数
  - 提供不确定性估计
  - 更精细的探索-利用平衡
- **适用场景**:
  - 参数空间较小（<20维）
  - 需要高精度优化
  - 计算成本较高的模型
- **优点**: 理论基础扎实，优化效果好
- **缺点**: 计算开销大，不适合高维空间

### 3. CMA-ES (Covariance Matrix Adaptation Evolution Strategy)
- **类型**: 进化策略
- **特点**:
  - 自适应协方差矩阵
  - 不依赖梯度信息
  - 适合连续参数优化
- **适用场景**:
  - 连续参数为主的搜索空间
  - 多峰优化问题
  - 需要全局搜索
- **优点**: 对参数尺度不敏感，鲁棒性好
- **缺点**: 对离散参数支持较弱

### 4. Random Search (随机搜索)
- **类型**: 基准方法
- **特点**:
  - 完全随机采样
  - 无智能引导
- **适用场景**:
  - 快速探索参数空间
  - 作为基准对比
  - 参数空间非常大时
- **优点**: 简单，无偏，易于并行
- **缺点**: 效率低，需要更多trials

## 使用建议

### 快速开始（推荐）
```
优化算法: TPE (贝叶斯优化)
Trials数: 50-100
评估方式: Holdout(快速)
启用剪枝: ✓
```

### 高精度优化
```
优化算法: Gaussian Process (高斯过程)
Trials数: 100-200
评估方式: KFold(稳健)
交叉验证折数: 5
启用剪枝: ✓
```

### 大规模搜索
```
优化算法: TPE (贝叶斯优化)
Trials数: 200-500
评估方式: Holdout(快速)
启用剪枝: ✓
最大采样数: 5000-10000
```

### 连续参数优化
```
优化算法: CMA-ES (进化策略)
Trials数: 100-200
评估方式: KFold(稳健)
```

## 技术细节

### TPE工作原理
1. 将历史试验分为"好"和"差"两组
2. 分别用Parzen估计器建模参数分布
3. 最大化"好"分布与"差"分布的比值来选择下一组参数

### GP工作原理
1. 用高斯过程拟合目标函数
2. 计算每个候选点的期望改进（Expected Improvement）
3. 选择EI最大的点作为下一个试验

### CMA-ES工作原理
1. 维护一个多元正态分布
2. 从分布中采样生成候选解
3. 根据评估结果更新分布的均值和协方差矩阵

## 常见问题

**Q: 应该选择哪种优化方法？**
A: 大多数情况下使用TPE即可。如果参数空间较小且需要高精度，可以尝试GP。

**Q: 需要多少trials？**
A: 一般50-100个trials足够。复杂模型或大搜索空间可能需要200-500个。

**Q: 是否应该启用剪枝？**
A: 建议启用。剪枝可以提前停止表现差的trial，节省时间。

**Q: Holdout vs KFold？**
A: Holdout更快，适合快速迭代；KFold更稳健，适合最终优化。

**Q: 贝叶斯优化比随机搜索好多少？**
A: 通常可以用更少的trials达到相同或更好的效果，节省50-80%的计算时间。
