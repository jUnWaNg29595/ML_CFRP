# 网络代理配置说明

## 1. 代理类型必须匹配端口

系统会把代理设置同时用于 PubChem、Hugging Face 和其他在线请求。地址可以填写完整 URL，也可以填写 `host:port`。

- SOCKS5：填写 `socks5://127.0.0.1:端口`，系统运行时使用 `socks5h`，由代理解析远端域名。
- HTTP：填写 `http://127.0.0.1:端口`，用于 HTTP CONNECT 代理。
- HTTPS：仅在代理软件明确提供 HTTPS 代理端口时使用。

`127.0.0.1:10808` 并不代表它一定是 SOCKS5。系统连接测试会读取端口响应并判断实际协议。

## 2. 连接测试结果

- “SOCKS5 握手成功”：端口确实提供 SOCKS5，且无协议层错误。
- “端口返回 HTTP 代理响应”：当前选择的类型错误，请将界面中的代理类型改为 HTTP。
- “HTTP 代理端口可连接，但代理服务器拒绝外部用户或要求认证”：本机端口已被占用并能返回代理响应，但代理服务策略拒绝访问；这不是 PubChem 或 Hugging Face 的 API 错误。
- “HTTP 代理要求认证”：在代理地址中填写认证信息，例如 `http://用户名:密码@127.0.0.1:8080`。密码包含 `@`、`:` 等特殊字符时应先进行 URL 编码。

协议不匹配时，系统不会继续向 PubChem/Hugging Face 发起请求，从而避免刷屏式的 `SOCKSHTTPSConnectionPool` 错误。

## 3. CCProxy 排查

如果本机使用 CCProxy：

1. 在 CCProxy 的端口设置中确认实际的 HTTP 和 SOCKS 端口，不要根据习惯直接使用 `10808`。
2. 如果连接测试提示“禁止外部用户”，检查外部访问、用户认证、IP 白名单和上网规则。
3. 如果只允许本机访问但系统运行在远程服务器，`127.0.0.1` 指向的是服务器本机，而不是开发电脑；需要在代理服务器上开放对应端口并填写可达地址。
4. 修改 CCProxy 配置后，重新启动代理服务，再在系统中点击“保存并应用”和“测试连接”。

## 4. 无代理运行

如果 PubChem/Hugging Face 可以直连，取消“启用代理”，点击“保存并应用”。系统会清理当前进程中的 `HTTP_PROXY`、`HTTPS_PROXY` 和 `ALL_PROXY` 环境变量；已下载的模型缓存不会被删除。
