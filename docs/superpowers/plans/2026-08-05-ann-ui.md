**Goal:** 将人工神经网络从少量通用参数升级为可复现的“基础模式 + 专业模式”独立配置卡片，并确保激活函数、Dropout、优化器、早停、学习率调度、梯度裁剪、AMP 等参数真实作用于训练，同时兼容旧参数和旧模型。

**Architecture:** 保留现有 sklearn 风格 `ANNRegressor`、外部 Pipeline 预处理和 PyTorch/DataParallel 结构；在 `ANNRegressor` 内增加参数校验、网络构建、训练控制和元数据记录，在 `model_trainer.py` 中只做 UI 参数到后端构造参数的映射。`app.py` 为 ANN 使用独立渲染分支，继续复用现有保存/加载参数机制，但不再让通用参数表覆盖 ANN 专属配置。

**Tech Stack:** Python 3.10、PyTorch、scikit-learn、pandas、NumPy、Streamlit、pytest、joblib。

## Global Constraints

- 不修改非 ANN 模型的训练行为和参数面板。
- 保留 `ANNRegressor` 的 sklearn API、`Pipeline` 外部预处理和旧模型加载能力。
- `scaler_type`、`normalize_target` 继续由外部训练 Pipeline 处理，不在 ANN 内部重复缩放。
- AMP、多 GPU、CUDA 不可用时必须安全回退，不得阻塞 CPU 训练。
- `validation_split` 只能从训练数据内部划分验证集，不得使用最终测试集。
- 所有 PowerShell 命令中的字符串值使用单引号。
- 不修改缓存、备份目录及与 ANN 无关的未跟踪文件。
- 本计划只包含实现和验证步骤，不自动执行 Git 提交或推送。

import joblib
import numpy as np
import pytest
import torch
import torch.nn as nn

from core.ann_model import ANNRegressor, FFN


def test_ffn_builds_gelu_and_dropout():
    model = FFN(4, [8, 4], activation='gelu', dropout_rate=0.25)
    modules = list(model.network.children())

    assert any(isinstance(module, nn.GELU) for module in modules)
    assert any(isinstance(module, nn.Dropout) for module in modules)


def test_ffn_omits_dropout_when_rate_is_zero():
    model = FFN(4, [8], activation='relu', dropout_rate=0.0)

    assert not any(isinstance(module, nn.Dropout) for module in model.network.children())


def test_ann_rejects_invalid_configuration_before_training():
    with pytest.raises(ValueError, match='dropout'):
        ANNRegressor(dropout_rate=0.9)

    with pytest.raises(ValueError, match='min_learning_rate'):
        ANNRegressor(learning_rate=1e-3, min_learning_rate=2e-3)


def test_ann_trains_without_validation_and_records_metadata():
    rng = np.random.default_rng(42)
    X = rng.normal(size=(24, 5))
    y = X[:, 0] * 0.5 + X[:, 1] * -0.2
    model = ANNRegressor(
        hidden_layer_sizes_str='8,4',
        epochs=2,
        batch_size=8,
        validation_split=0.0,
        early_stopping=False,
        device='cpu',
        use_amp=False,
        verbose=False,
    )

    model.fit(X, y)

    assert len(model.train_loss_history) == 2
    assert model.validation_loss_history == []
    assert model.training_metadata_['device'] == 'cpu'
    assert model.training_metadata_['effective_batch_size'] >= 1


def test_ann_can_be_serialized_after_training(tmp_path):
    X = np.arange(40, dtype=float).reshape(20, 2)
    y = X[:, 0] + X[:, 1]
    model = ANNRegressor(
        hidden_layer_sizes_str='4',
        epochs=1,
        batch_size=4,
        device='cpu',
        use_amp=False,
        verbose=False,
    ).fit(X, y)
    path = tmp_path / 'ann.joblib'

    joblib.dump(model, path)
    restored = joblib.load(path)

    np.testing.assert_allclose(model.predict(X[:3]), restored.predict(X[:3]))
