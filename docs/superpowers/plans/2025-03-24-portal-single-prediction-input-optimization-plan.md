# 邹华维课题组材料预测平台：单组输入工作台交互与多模态输入优化实施计划

> **设计规范文件**：`docs/superpowers/specs/2025-03-24-portal-single-prediction-input-optimization-spec.md`  
> **目标**：重构 `UserPrediction.py` 中的单组材料预测输入工作台，提供“经典预设 + 手动粘贴 + 截图 OCR + 在线 2D 画板”的多模态输入矩阵、即时 2D 分子图看板、工艺参数物理引导，并保留 AI 自然语言提取一键回填能力。

---

## 阶段一：封装多模态分子输入组件 (`UserPrediction.py`)

### 1.1 课题组经典预设单体库定义
- [ ] 在 `UserPrediction.py` 中定义 `PORTAL_PRESET_RESINS` 和 `PORTAL_PRESET_HARDENERS` 字典，包含常用双酚类、芳香胺、酸酐等经典单体。

### 1.2 实时 2D 分子图渲染辅助函数 (`_render_smiles_preview_box`)
- [ ] 编写轻量高效的 SMILES 实时语法校验与 2D 拓扑结构绘制函数，采用内存缓存避免重复渲染。
- [ ] 语法校验失败时输出明确的中文提示（如“括号未配对”、“原子价态不合法”）。

### 1.3 多模态复合输入组件 (`render_multimodal_smiles_field`)
- [ ] 封装包含 4 个 Tab 的复合输入组件：
  - `🏷️ 经典预设`：分类下拉一键选择填入；
  - `✏️ 手动输入`：文本框直接粘贴并触发即时语法自检；
  - `📷 截图识别`：集成已有的图片上传与剪贴板识别；
  - `🎨 2D画板`：嵌入轻量 JSME 画板组件，一键同步回填 SMILES。
- [ ] 每个字段右侧/下方同步展示实时 2D 拓扑图。

---

## 阶段二：重构单组表单交互与 AI 智能回填联动 (`UserPrediction.py`)

### 2.1 表单字段渲染升级 (`render_single_input_form`)
- [ ] 将原有的普通文本框式 SMILES 输入替换为新的 `render_multimodal_smiles_field`。
- [ ] 为工艺参数（温度、时间、phr）配置标准物理单位（`°C`, `h`, `phr`）与合理区间提示。

### 2.2 AI 自然语言提取结果一键回填机制
- [ ] 优化 AI 输入助手提取后的【一键采纳并填入表单】流程，确保自动同步更新所有多模态输入组件与 2D 分子图预览状态。

---

## 阶段三：预测前健康检查与结果呈现优化

### 3.1 预测前自检条 (Pre-flight Health Check)
- [ ] 在点击预测前实时显示输入就绪状态（`✅ 树脂结构有效`、`✅ 固化剂结构有效`、`✅ 工艺参数完整`），避免异常阻断。

### 3.2 预测结果对比与微调闭环
- [ ] 增强预测结果卡片，提供【基于当前输入快速微调】按钮，方便师生连续测试。
