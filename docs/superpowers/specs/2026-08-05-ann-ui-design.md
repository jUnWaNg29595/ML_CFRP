# ANN 人工神经网络参数面板优化设计

## 1. 背景与目标

当前系统的人工神经网络界面只暴露了少量训练参数。部分界面参数（例如激活函数和 Dropout）虽然可以填写，但 `ANNRegressor` 训练时会被忽略，造成“界面可调、训练不生效”的问题。

本次优化目标：

- 提供“基础模式 + 专业模式”的 ANN 独立配置卡片；
- 让界面显示的关键参数真正传递到训练后端；
- 支持小样本、GPU 和高容量网络的常用训练场景；
- 保持旧模型参数、旧导出模型和现有非 ANN 模型兼容；
- 保存完整训练配置和训练过程信息，保证预测、解释和虚拟筛选可复现。

## 2. 范围

### 包含

- ANN 独立参数卡片；
- ANN 参数预设；
- 激活函数、Dropout、优化器、权重衰减；
- 验证集、早停、学习率调度；
- 梯度裁剪、设备、AMP 和多 GPU；
- 参数校验、兼容默认值和训练日志；
- ANN 配置和训练历史的导出/恢复；
- 参数 schema、训练、预测和导出回归测试。

### 不包含

- 修改其他神经网络模型的参数面板；
- 重写通用模型训练流程；
- 引入新的深度学习框架；
- 自动搜索 ANN 超参数；
- 改变现有数据切分策略。

## 3. 用户界面设计

ANN 选择后显示独立配置卡片，分为四个区域：

### 3.1 网络结构

- 隐藏层结构：文本输入，例如 `256,128,64`；
- 激活函数：ReLU、GELU、SiLU、ELU、Tanh、LeakyReLU；
- Dropout：`0.0–0.8`；
- 显示网络结构摘要和估计参数规模。

### 3.2 基础训练参数

- 学习率；
- 批大小；
- 最大训练轮数；
- 随机种子；
- 特征缩放方式；
- 是否归一化目标值。

### 3.3 专业设置

折叠展开后显示：

- 优化器：Adam、AdamW、RMSprop、SGD；
- 权重衰减；
- 验证集比例；
- 是否启用早停；
- patience；
- min_delta；
- 学习率调度器：无、ReduceLROnPlateau、CosineAnnealing；
- scheduler factor；
- 最小学习率；
- 梯度裁剪阈值；
- 设备：auto、CPU、CUDA；
- 是否启用多 GPU；
- 是否启用 AMP。

### 3.4 预设

提供四个按钮：

- **稳健小样本**：较小网络、较低学习率、适度 Dropout、启用验证和早停；
- **快速 GPU**：较大 batch size、AMP、较少日志；
- **高容量网络**：更宽的隐藏层和更高训练轮数，仅建议样本量较大时使用；
- **恢复默认**：恢复 ANN 默认配置。

切换预设只更新 ANN 参数，不改变其他模型或全局训练设置。

## 4. 参数传递设计

界面参数统一转换为 `ANNRegressor` 的构造参数：

| UI 参数 | 后端含义 |
|---|---|
| `hidden_layer_sizes` | 解析为隐藏层宽度列表 |
| `activation` | 每个隐藏层使用的激活函数 |
| `dropout_rate` | 每个隐藏层后的 Dropout |
| `optimizer` | 优化器类型 |
| `learning_rate` | 初始学习率 |
| `weight_decay` | L2 权重衰减 |
| `gradient_clip` | 梯度裁剪阈值，0 表示关闭 |
| `validation_split` | 训练集内部验证比例 |
| `early_stopping` | 是否启用早停 |
| `patience` | 连续无改善轮数 |
| `min_delta` | 最小改善幅度 |
| `lr_scheduler` | 学习率调度策略 |
| `scheduler_factor` | ReduceLROnPlateau 衰减因子 |
| `min_learning_rate` | 学习率下限 |
| `scaler_type` | 外部特征缩放器 |
| `normalize_target` | 外部目标缩放器 |
| `device` | CPU/GPU 自动选择 |
| `use_data_parallel` | 多 GPU DataParallel |
| `use_amp` | CUDA 混合精度 |

现有训练器中的临时丢弃逻辑需要移除：`activation`、`dropout_rate` 不再作为不支持参数删除。

## 5. 训练数据流

1. 训练器读取 UI 参数并执行 schema 校验；
2. 外部 Pipeline 执行缺失值填充、特征缩放和可选目标缩放；
3. `ANNRegressor` 根据隐藏层、激活函数和 Dropout 创建网络；
4. 根据优化器和正则化参数创建优化器；
5. 按 `validation_split` 从训练数据内部划分验证集；
6. 每个 epoch 计算训练损失和验证损失；
7. 根据早停策略保存最佳权重；
8. 根据调度器更新学习率；
9. 训练结束后将模型权重移回 CPU，保持现有序列化行为；
10. 保存有效参数、训练历史和设备信息。

验证集只从训练数据内部划分，不使用最终测试集，避免数据泄漏。

## 6. 参数校验与异常处理

- 隐藏层字符串必须解析为正整数列表；
- Dropout 必须在 `[0, 0.8]`；
- 学习率、权重衰减和最小学习率必须为正数；
- `min_learning_rate` 不得大于 `learning_rate`；
- `validation_split` 限制在 `[0, 0.4]`；
- `patience` 必须为非负整数；
- `gradient_clip=0` 表示关闭；
- 样本量不足时自动限制验证集大小并给出提示；
- AMP、多 GPU 或 CUDA 不可用时自动回退到 CPU；
- 训练失败时展示实际生效参数和可执行的降级建议。

## 7. 兼容性

- 旧参数缺失时使用兼容默认值；
- 旧参数名 `hidden_layer_sizes` 继续支持；
- 旧导出模型不要求重新训练即可加载；
- 旧模型未保存新字段时，预测阶段使用默认配置；
- `dropout_rate=0` 时网络行为等价于无 Dropout；
- `validation_split=0` 时关闭内部验证和早停；
- 非 ANN 模型不读取 ANN 专属参数。

## 8. 记录与导出

训练元数据至少包含：

- 完整 ANN 配置；
- 实际有效 batch size；
- 实际设备和 GPU 数量；
- AMP 和多 GPU 是否启用；
- 最佳 epoch；
- 最终学习率；
- 是否早停；
- 早停原因；
- 训练和验证损失曲线。

这些信息应随模型或训练结果一同保存，供模型解释、预测和虚拟筛选复用。

## 9. 测试方案

### 参数层

- 默认参数完整；
- 非法参数被拒绝或安全修正；
- 旧参数名可以映射；
- 预设只修改 ANN 参数。

### 网络层

- 不同激活函数实际创建对应模块；
- Dropout 大于 0 时网络包含 Dropout；
- Dropout 为 0 时不包含 Dropout；
- 不同隐藏层配置产生预期网络结构。

### 训练层

- Adam、AdamW、RMSprop、SGD 均可创建；
- 权重衰减和梯度裁剪生效；
- 早停可以保存最佳权重；
- 学习率调度器可以更新学习率；
- 无验证集时仍能正常训练。

### 兼容层

- 旧 ANN 参数可以创建模型；
- 模型导出后可重新加载并预测；
- CPU 环境下 GPU 参数安全回退；
- 非 ANN 模型训练测试不受影响。

## 10. 实施顺序

1. 抽取 ANN 参数 schema 和默认值；
2. 扩展 `ANNRegressor` 网络结构和训练控制；
3. 修改模型训练器参数映射；
4. 替换 ANN UI 为独立配置卡片；
5. 增加预设和参数校验提示；
6. 增加配置、训练、导出回归测试；
7. 运行 ANN 相关测试、全量语法检查和兼容性测试。
