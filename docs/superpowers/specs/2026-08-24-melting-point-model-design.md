# 熔点数据集、QSPR 模型与虚拟筛选设计

## 1. 目标

为虚拟分子筛选增加可审计的熔点模型过滤，并建立 PubChem 自动采集、清洗、导出和训练的闭环。熔点模型只用于分子/组分熔点估计，不替代 Tg 模型，也不再把经验公式作为模型结果。

## 2. 设计原则

- 使用 PubChem 自动采集为主，保留 CID、原始文本和来源信息。
- 树脂和固化剂共享统一熔点 QSPR 模型，但按角色和固化剂类别分层评估。
- 树脂与固化剂在筛选页面分别设置阈值。
- 高质量单值记录默认进入训练；范围、估算、分解和混合物记录默认不进入训练。
- 所有候选必须复用熔点模型导出的分子特征 workflow。
- 适用域外、特征无法复现或不确定度过高的候选标记为 `unknown`，不自动判定为低熔点。
- 新熔点过滤默认采用“仅标记不剔除”，经过验证后才启用严格过滤。

## 3. 数据采集与存储

### 3.1 PubChem 查询

页面分别配置：

- 树脂 SMARTS 查询；
- 固化剂类别查询；
- 树脂和固化剂各自的 CID 上限；
- 每类候选采样上限；
- 随机种子和并发参数。

流程为：获取 CID → 批量获取结构 → 获取熔点注释 → 解析单位和数值 → RDKit 复核 → canonical SMILES 去重 → 写入数据集。

每个查询独立缓存，网络失败时保留已完成结果并支持再次继续。

### 3.2 数据集字段

整理后的数据集至少包含：

| 字段 | 含义 |
| --- | --- |
| `cid` | PubChem 化合物 CID |
| `smiles` | 规范化 SMILES |
| `mp_c` | 训练用摄氏度熔点；范围记录默认为空 |
| `mp_lower_c` / `mp_upper_c` | 范围或不确定记录的上下限 |
| `mp_raw` | PubChem 原始熔点文本 |
| `mp_unit_raw` | 原始温度单位 |
| `mp_quality` | `high`、`range`、`estimated`、`decomp`、`mixture`、`unparsed` |
| `component_role` | `resin`、`hardener`、`other` |
| `hardener_class` | 胺、酸酐、酚、硫醇、咪唑或其他 |
| `source` / `source_url` | 数据来源及链接 |
| `canonical_smiles` | 用于去重的规范结构 |
| `is_salt` / `is_mixture` | 结构质量标记 |

原始记录和整理后数据分别保存到 `cache/pubchem` 与 `results/melting_point_dataset`，不覆盖用户原始数据。

### 3.3 清洗与去重

- 自动转换摄氏度、华氏度和开尔文，并保留原始单位。
- 明确单值进入高质量候选；范围只保存上下限。
- `约`、`>`、`<`、`分解`、`软化`、混合物等信息保留原文并降低质量等级。
- 无法解析的文本进入原始表，不进入默认训练表。
- 按 `canonical_smiles` 去重；优先保留高质量、来源完整、非盐、非混合物记录。
- 训练前显示总记录数、高质量记录数、角色分布、类别分布和被排除原因。

## 4. 模型训练

- 复用现有模型训练页和模型导出机制。
- 自动使用 `mp_c` 作为目标列，目标单位固定为 `°C`。
- SMILES 分子特征严格来自当前模型选择的 workflow。
- `component_role` 和 `hardener_class` 可作为类别特征或分层分析字段。
- 模型 artifact 增加 `task_kind=melting_point`、`target_unit=C`、数据集指纹和 workflow 指纹。
- 至少报告总体 MAE、RMSE、R² 和有效样本数。
- 分别报告树脂、胺、酸酐、酚、硫醇、咪唑等子集指标；样本不足时显示“不可评估”。
- 训练集、验证集和数据来源信息随训练记录保存，便于复现和回退。

## 5. 虚拟筛选集成

### 5.1 控件

在虚拟筛选页面增加熔点模型面板：

- 启用/关闭熔点模型过滤；
- 选择已训练熔点模型；
- 树脂最大预测熔点；
- 固化剂最大预测熔点；
- 最大预测标准差；
- 最低适用域分数；
- `仅标记不剔除` / `严格过滤`。

默认模式为仅标记不剔除。

### 5.2 预测数据流

候选树脂和固化剂按 canonical SMILES 去重，只对唯一分子提取一次熔点模型特征；随后按配方键回填结果。模型调用前验证 feature workflow、特征顺序、目标单位和 artifact 类型。

配方结果增加：

- `resin_mp_observed` / `hardener_mp_observed`；
- `resin_mp_predicted_c` / `hardener_mp_predicted_c`；
- `resin_mp_std_c` / `hardener_mp_std_c`；
- `resin_mp_ad_score` / `hardener_mp_ad_score`；
- `resin_mp_filter_status` / `hardener_mp_filter_status`；
- `mp_filter_reason`。

### 5.3 严格过滤规则

候选只有同时满足以下条件才通过：

`预测熔点 + 预测标准差 <= 角色阈值`，且适用域分数达到设定下限，且模型输入 workflow 完整复现。

缺失模型、缺失特征、适用域外或不确定度不可用时状态为 `unknown`，不静默通过。

## 6. 错误处理与可观测性

- PubChem 查询按类别隔离失败，单类失败不影响其他类别。
- 页面显示各阶段进度、缓存命中率、记录数和排除原因。
- 模型预测失败时停止熔点过滤并保留候选池，不返回伪造预测。
- 任何单位无法确认的模型禁止进入严格过滤。
- 所有筛选结果记录模型 ID、数据集指纹、阈值、模式和时间。

## 7. 验证策略

### 单元测试

- 熔点文本单值、范围、摄氏度/华氏度/开尔文转换；
- 约、分解、软化和无法解析文本的质量标记；
- canonical SMILES 去重和优先级；
- 树脂/固化剂独立阈值；
- 不确定度和适用域门控；
- 熔点模型 artifact 与 workflow 契约校验。

### 集成冒烟测试

- 使用小型固定 PubChem 缓存完成数据集生成；
- 训练一个轻量回归模型并导出 artifact；
- 对树脂和固化剂候选执行仅标记模式与严格模式；
- 验证原有 Tg 筛选输出和模型调用不受影响。

## 8. 验收标准

1. 能按树脂/固化剂分别从 PubChem 采集并缓存熔点原始记录。
2. 能导出含来源和质量字段的熔点训练数据集。
3. 能从现有训练页训练并保存带熔点任务元数据的模型。
4. 虚拟筛选页能加载该模型并分别应用树脂、固化剂阈值。
5. 结果可区分实测值、预测值、标准差、适用域和过滤原因。
6. 数据不足、单位不明、特征不匹配或适用域外时不会伪造通过结果。
7. 原有 Tg 筛选回归测试通过。
