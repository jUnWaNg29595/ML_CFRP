# CFRP PPT 视觉升级设计

## 目标

在不增加页数、不改变事实内容和不展示虚构数据的前提下，降低“标题 + 方框 + 底部结论”的重复感，使重点页面直接表达分子结构、工作流、候选队列和可追溯闭环。

## 方案

采用“重点重绘 + 全局统一”：

- 全局统一页眉、页脚、字号层级、连接线和颜色语义。
- 重点页使用不同的视觉语法：
  - 1、32：分子网络和闭环式封面/总结。
  - 5、12、14、16、20：主链路、时间线、计算链和步骤轨道。
  - 8、13、17、18、19、21：角色泳道、方法矩阵、契约交集、错误分流和稀疏矩阵。
  - 24、25、26、27、28、29、30、31：候选漏斗、来源汇流、过滤栈、设计空间、批次队列、唯一结构复用、联合评分和闭环网络。
- 普通内容页保留原有信息，但使用更弱边框、更强留白和少量图形标记，避免所有页面都呈卡片墙。

## 视觉规则

- 深蓝表示模型/契约，青绿色表示特征/数据流，黄色表示决策/警示，浅灰只做背景。
- 关系优先用箭头、轨道、节点和分支表达；只有需要承载段落时才使用容器。
- 不使用没有数据依据的比例、性能数字或命中率；抽象图只表达流程关系。
- 保留 16:9、Microsoft YaHei/Arial、32 页和现有中文内容结构。

## 验收

- 重点页不再依赖三列等宽方框表达主关系。
- 页面缩略图具有至少 4 种明显版式：网络、时间线/泳道、矩阵/漏斗、队列/闭环。
- 编译、lint、PPTX 审计和文本抽取通过；无乱码、缺页或标题重叠。
