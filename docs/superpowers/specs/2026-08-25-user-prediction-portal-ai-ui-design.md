# 用户预测门户科研 UI 与多模型 AI 辅助设计

- 日期：2026-08-25
- 范围：UserPrediction.py 用户预测门户、主平台 AI 配置、受控 Python 预测任务
- 目标端口：8555
- 状态：已获用户确认，待编写实施计划

## 1. 目标与边界

将现有用户预测门户升级为深蓝实验室风格的科研预测工作台，并接入可配置的 OpenAI 兼容 AI 服务。首期以 DeepSeek 为默认示例，但不把门户实现绑定到单一厂商。

Python 是可信的计算执行层，负责分子特征工程、xTB/描述符流程、模型加载、预处理、CFRP 预测和后台任务。AI 只负责自然语言输入解析、结构化字段建议、缺失项提示、结果解释和受控任务编排。AI 不执行任意 Python、PowerShell 或系统命令，不修改模型、特征流程、配置文件或训练数据。所有 AI 解析字段必须人工确认后才能进入预测。保留 8555 独立运行、现有手动预测、批量预测和主平台门户开关。

首期不实现完整前后端拆分、多用户远程账号体系、AI 自主实验设计和 AI 直接控制 xTB。

## 2. 目标架构

### 2.1 页面层

UserPrediction.py 负责深蓝实验室风展示、材料与性能选择、AI 辅助输入、结构化确认、任务状态和结果展示，并兼容手动输入和批量上传。页面层不直接实现厂商 API 请求，不直接拼装分子特征，也不决定模型特征顺序。

### 2.2 AI 服务层

建议新增：

- core/portal_ai.py：OpenAI 兼容客户端、超时、重试、响应适配和错误分类。
- core/portal_ai_schema.py：输入建议、警告、置信度和结果解释数据契约。
- core/portal_ai_config.py：服务配置读取、校验、脱敏和默认服务选择。

首期调用：POST {base_url}/chat/completions，并使用 Bearer API Key。默认解析 choices[0].message.content，同时兼容 JSON 字符串、Markdown JSON 代码块和有限的厂商字段差异。

### 2.3 配置与门户共享

主平台管理页负责写入受保护的本地 AI 服务配置；用户门户只读取经过校验的启用配置，不向浏览器暴露 API Key。配置读取应复用现有门户的本地配置目录或独立服务层，不把密钥写入公开的 prediction_config.json。主平台保存配置时创建备份并校验 base_url、模型名、超时和用途；门户读取失败或配置损坏时自动降级为无 AI 模式。

### 2.4 Python 计算层

Python 继续负责 SMILES/BigSMILES/多组分校验、分子特征流程复现、xTB 或其他外部特征程序的受控调用、特征拼接与顺序校验、预处理、已发布模型加载、环氧体系和 CFRP 预测，以及单样本、批量和后台任务。AI 只能提交符合 schema 的任务请求，计算层必须再次校验。

## 3. 用户界面设计

### 3.1 首页

采用“先选材料方向，再进入预测工作台”的 A 方案：顶部品牌栏 CFRP / PREDICT；显示门户、模型和 AI 服务状态；主视觉标题为“从材料输入到可复现预测”；主视觉区放置 DeepSeek 输入助手主入口；材料卡片展示环氧树脂体系、单向碳纤维复合材料及未来可扩展方向，并显示性能数量、已发布模型数量和模型状态。

### 3.2 视觉与图标

采用深蓝实验室风：深蓝用于导航和工作区，青蓝突出 AI/计算状态，绿色表示通过，琥珀色表示人工确认，红色表示阻断错误，灰蓝色表示辅助信息。统一使用线性 SVG 图标，不再混用 emoji，覆盖材料、树脂、固化剂、碳纤维、输入、校验、特征、计算、结果、AI、下载和任务状态。

### 3.3 AI 输入流程

DeepSeek 位于首页主视觉区。流程为：自然语言输入 -> AI 结构化解析 -> 字段确认页 -> Python 校验 -> 用户确认 -> 创建预测任务。确认页显示字段类别、字段名、AI 建议值、状态、警告、假设和编辑控件。所有字段默认需要人工确认；关键结构字段必须通过既有结构校验；AI 不得静默补齐关键分子特征。

### 3.4 预测工作台

任务阶段固定为：输入确认 -> 结构校验 -> 特征准备 -> 模型计算 -> 结果解释。显示任务 ID、当前阶段、进度、已完成步骤、模型版本、特征流程标识和错误摘要，并提供暂停、取消和失败重试入口（以后台任务能力为准）。

### 3.5 结果页

结果分为核心预测值/单位/模型版本/完成时间/可信状态，输入与计算摘要，以及 AI 辅助解释和实验建议。AI 解释只能读取 Python 返回的结果摘要，不得改写预测值、隐藏越界警告或把相关性表述为确定因果关系。

## 4. AI 服务配置

主平台管理页新增 AI 服务配置，支持多个服务并按用途选择启用服务。字段包括服务名称、厂商标识、接口类型、base_url、API Key、模型名称、用途（输入解析/结果解释/两者）、超时、最大输出 token、Temperature 和启用状态。

DeepSeek 可作为默认服务，也可配置通义、智谱、OpenAI、Ollama 或内部部署模型；只要提供 OpenAI 兼容接口即可接入。内部保留响应适配层以便以后支持特殊厂商。

API Key 只在服务端读取和使用；管理页面脱敏显示；不写入 UserPrediction.py；导出配置时排除；日志禁止输出 Key、完整请求正文和敏感输入。缺少完整管理员认证时至少实施本地配置权限、脱敏、导出过滤和日志脱敏。

## 5. 数据契约

### 5.1 AI 解析请求

请求上下文包含 material_type、target、available_fields、user_text 和安全规则，例如 must_confirm_before_prediction、do_not_generate_missing_molecular_features、do_not_execute_code。

允许返回 recognized_fields、suggestions、missing_fields、warnings、assumptions 和 confidence。不确定内容必须返回 null 或放入警告，不得编造。

### 5.2 Python 预测任务

用户确认后创建包含 task_id、material_type、target、inputs、model_id、feature_workflow_id、source 和 confirmed_by_user 的任务。执行前强制检查字段、模型发布状态、特征流程、输入列、结构合法性、数值范围、确认状态和未知字段。

### 5.3 任务状态

统一状态为 queued、validating、featuring、predicting、explaining、completed、failed、cancelled。页面通过任务 ID 获取状态，避免 Streamlit 长时间阻塞；刷新页面后应能恢复任务状态和结果。

## 6. 失败降级与安全

AI 不可用时，手动输入和批量上传继续工作；已确认的普通 Python 预测不依赖 AI 解释完成；结果页显示 AI 解释不可用；认证失败、超时、限流和解析失败分别提示；保留任务 ID 和管理员诊断日志。

AI 严禁执行任意代码或命令，修改模型/特征流程/配置/训练数据，提交未经确认的预测，生成或覆盖新的模型数值，或隐藏结构解析失败、越界和模型不可用信息。

## 7. 兼容与迁移

保留 8555 独立启动、主平台门户开关、手动单样本预测、CSV/Excel 批量预测、已发布模型配置和模型目录。新功能增量接入；未配置 AI 时仍可使用原有预测路径；旧模型不自动修改；缺少完整特征流程的模型不能借 AI 绕过契约检查。

## 8. 分阶段实施

1. UI 重构：深蓝实验室风首页、材料卡片、线性 SVG 图标、预测工作台和任务状态。
2. AI 配置：多服务配置、OpenAI 兼容请求、Key 脱敏、导出过滤和连通性测试。
3. AI 输入助手：首页主入口、自然语言解析、结构化确认、Python 校验和确认后提交。
4. 后台任务与结果解释：任务 ID、阶段进度、分子特征后台执行、取消/重试、结果摘要和 AI 解释。

## 9. 验收标准

### UI

- 首页可选择环氧树脂和单向 CFRP。
- DeepSeek 入口位于首页主视觉区且清晰可见。
- 图标统一，不再混用 emoji。
- 常见桌面宽度无横向溢出。
- 预测阶段和服务状态始终可见。

### AI

- 未配置 API Key 时手动预测仍可用。
- API Key 不出现在浏览器、导出配置和日志。
- 非标准 JSON 可降级解析或给出明确错误。
- AI 字段必须人工确认，不能直接触发未经确认的预测。
- 多种 OpenAI 兼容服务可配置切换。

### Python 计算

- 分子特征工程调用既有 Python 流程。
- BigSMILES/SMILES 校验与训练流程一致。
- xTB、描述符和模型预处理不被 AI 绕过。
- CFRP 预测使用已发布模型和特征契约。
- 长任务有任务 ID、阶段状态和错误摘要。
- 刷新页面后可恢复任务状态。

### 兼容性

- 8555 启动方式和主平台门户开关继续有效。
- 现有模型配置不被覆盖。
- AI 未配置时旧预测路径可用。
- 配置迁移失败时保留备份并回退。
