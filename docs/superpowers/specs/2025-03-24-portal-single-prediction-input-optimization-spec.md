# 邹华维课题组材料预测平台：单组输入工作台交互与多模态输入优化规范

**设计日期**：2025-03-24  
**所属模块**：邹华维课题组材料预测平台 (`UserPrediction.py`) / 预测工作台单组输入  
**状态**：已批准（Approved）

---

## 1. 概述与设计目标

### 1.1 背景与用户痛点
当前 `UserPrediction.py` 在单组配方/工艺输入时存在以下阻碍：
1. **SMILES 输入门槛高、容错低**：纯手动输入/粘贴复杂 SMILES 容易因漏字符或括号不配对导致后端报错；
2. **缺乏即时视觉确认反馈**：输入后无即时 2D 分子图呈现，用户无法直观确认分子结构是否正确；
3. **输入模态单一**：缺少针对文献截图识别（OCR）、在线手绘分子（JSME 画板）及课题组经典单体一键回填的多模态支持；
4. **工艺参数缺乏物理域引导**：缺少单位和典型合理范围提示，容易输入非物理极端值。

### 1.2 重构目标
为邹华维课题组师生构建**“零障碍、多模态、即时视觉反馈、智能引导”**的单组材料预测工作台：
1. **多模态分子结构输入矩阵**：包含【课题组经典单体预设】、【手动粘贴 SMILES + 实时语法自检】、【文献截图/图片 OCR 识别】、【在线 2D 分子画板 (JSME)】；
2. **输入即时 2D 拓扑结构图呈现**：任何输入方式均在右侧/下方即时呈现高清 2D 分子结构图；
3. **保留并强化 AI 输入助手**：支持文献自然语言段落一键解析与结构化回填；
4. **工艺参数物理范围提示与预测前自检**：提供单位和物理区间提示，并在预测前进行轻量健康检查，杜绝底层异常抛错。

## 2. 系统架构与交互数据流

```
[ 单组输入工作台 (Single-Sample Workbench) ]
  ├── 1. AI 智能输入助手 (可选) ── 粘贴文献描述 -> AI 结构化提取 -> 一键回填到下方表单
  │
  ├── 2. 多模态分子结构输入组件 (针对每个 SMILES 字段)
  │      ├─ Tab A: 经典单体预设 (E-51, AG-80, 4,4'-DDS, DDM, MTHPA, 芴基环氧等一键选择)
  │      ├─ Tab B: 手动输入/粘贴 SMILES (带即时 RDKit 语法解析与红字校验提示)
  │      ├─ Tab C: 图片/截图识别 OCR (拖入截图/Ctrl+V 粘贴 -> DECIMER 自动转 SMILES)
  │      └─ Tab D: 在线 2D 分子画板 (JSME 画板交互 -> 一键导出标准 SMILES)
  │      │
  │      ▼
  │   [ 实时 2D 分子拓扑看板 (即时渲染 RDKit 2D 高清分子图) ]
  │
  ├── 3. 工艺与配比参数面板 (带物理单位与常见区间提示，如 phr [10~120], 固化T [80~240°C])
  │
  ▼
[ 预测前自检与执行 (Pre-flight Health Check & Execution) ]
  ├── 实时校验各字段完整性与化学合法性 (显示绿色就绪标签)
  ├── 点击【开始可复现预测】
  │
  ▼
[ 预测结果与对比分析 (Result Presentation & Comparison) ]
  ├── 大字呈现预测值 (如 Tg = 192.5 °C) + 置信区间 / 标准差
  ├── 自动计算与经典体系差值对比
  └── 提供【基于当前配方继续微调】快捷按钮
```

## 3. 详细功能模块设计

### 3.1 课题组经典预设单体库（Preset Library）
在每个分子结构输入项顶部提供常用单体快速下拉选单，选定后自动同步到文本框并触发 2D 图渲染：
- **环氧树脂常用单体**：
  - 双酚A二缩水甘油醚 (E-51 / DGEBA): `CC(C)(c1ccc(OCC2CO2)cc1)c1ccc(OCC2CO2)cc1`
  - 双酚F环氧树脂 (DGEBF): `C1OC1COc1ccc(Cc2ccc(OCC3CO3)cc2)cc1`
  - 双酚S环氧树脂 (DGEBS): `C1OC1COc1ccc(S(=O)(=O)c2ccc(OCC3CO3)cc2)cc1`
  - 四缩水甘油基二氨基二苯甲烷 (AG-80 / TGDDM): `C1OC1CN(CC2CO2)c3ccc(Cc4ccc(N(CC5CO5)CC6CO6)cc4)cc3`
  - 三缩水甘油基对氨基苯酚 (AFG-90 / TGDAP): `C1OC1CN(CC2CO2)c3ccc(OCC4CO4)cc3`
  - 酚醛环氧树脂骨架 (EPN): `C1OC1COc1cccc(Cc2cccc(OCC3CO3)c2)c1`
  - 芴基双酚环氧树脂 (BHPF-EP): `C1OC1COc2ccc3c(c2)C4(c5ccccc5-c3c4)c6ccc(OCC7CO7)cc6`
  - 脂环族环氧 (TDE-85): `O=C(OCC1CO1)C2CCCC2C(=O)OCC3CO3`
- **固化剂常用单体**：
  - 4,4'-二氨基二苯砜 (4,4'-DDS): `Nc1ccc(S(=O)(=O)c2ccc(N)cc2)cc1`
  - 3,3'-二氨基二苯砜 (3,3'-DDS): `Nc1cccc(S(=O)(=O)c2cccc(N)c2)c1`
  - 4,4'-二氨基二苯甲烷 (DDM): `Nc1ccc(Cc2ccc(N)cc2)cc1`
  - 4,4'-二氨基二苯醚 (ODA): `Nc1ccc(Oc2ccc(N)cc2)cc1`
  - 异佛尔酮二胺 (IPDA): `CC1(C)CC(C)(CN)CC(N)C1`
  - 甲基四氢苯酐 (MTHPA): `CC1=CCC2C(=O)OC(=O)C2C1`
  - 甲基六氢苯酐 (MHHPA): `CC1CCC2C(=O)OC(=O)C2C1`
  - 间苯二胺 (m-PDA): `Nc1cccc(N)c1`
  - 联苯二胺 (DAB): `Nc1ccc(-c2ccc(N)cc2)cc1`

### 3.2 多模态分子输入组件封装（`render_multimodal_smiles_input`）
针对 `UserPrediction.py` 中每个 SMILES 类型的输入字段，封装统一的多模态输入 UI：
- **Tabs 布局**：
  - `🏷️ 经典预设`：分类下拉一键填入；
  - `✏️ 手动输入`：文本框直接粘贴，内置 `Chem.MolFromSmiles` 即时校验；
  - `📷 截图识别`：集成 DECIMER 剪贴板粘贴与图片上传；
  - `🎨 2D画板`：嵌入 JSME 组件（轻量纯前端 HTML5 架构）。
- **即时 2D 分子图看板**：
  - 只要获取到合法 SMILES，立即调用 `Draw.MolToImage` 渲染 $300 \times 200$ 高清分子图并展示在输入框右侧或下方。

### 3.3 保留并强化的 AI 输入助手
- 用户在页面顶部展开【🤖 AI 智能辅助填写】；
- 粘贴自然语言描述后，AI 提取字段以清晰的表格/卡片展示；
- 用户点击【一键采纳并填入表单】，自动触发底层表单状态更新与全套分子图即时渲染。

### 3.4 工艺与配比参数物理域指引
- 在表单的每个数字输入框（`number_input`）上，配置精准的 `help` 提示和合理的 `min_value` / `max_value`；
- 增加常见物理单位后缀（如 `°C`, `h`, `phr`, `g/eq`, `MPa`）；
- 预测前动态评估输入就绪状态（Health Check Badge），提供友好反馈。

---

## 4. 验收标准

1. 用户在单组预测页面输入分子时，能够自由在“经典预设、手动粘贴、截图识别、2D分子画板”之间无缝切换；
2. 输入有效 SMILES 后，页面即刻呈现高清 2D 分子拓扑图；输入非法 SMILES 时，即时提示语法错误；
3. AI 输入助手的自然语言提取与一键回填功能正常工作且与表单无缝联动；
4. 预测执行流程顺畅无阻，不再出现由于 SMILES 错漏或特征缺失导致的不可预期崩溃。
