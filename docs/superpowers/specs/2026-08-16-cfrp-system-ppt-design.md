# CFRP 智能预测平台全流程科研汇报 PPT 设计

## 目标

制作一套约 25 分钟、约 32 页的中文学术方法汇报 PPT，完整介绍 CFRP 智能预测平台的真实工作流，并重点解释分子特征工程与配方级高通量筛选。PPT 不展示虚构实验结果，不介绍当前尚不成熟的主动学习模块。

## 受众与场景

- 受众：学术答辩/论文汇报听众。
- 场景：论文方法与系统介绍。
- 信息密度：中等偏高；每页只保留一个主结论，复杂机制拆成多页。
- 交付：可编辑 PowerPoint `.pptx`，中文正文清晰适配投影。

## 叙事结构

1. **研究问题与系统定位**：说明 CFRP 配方性能预测为何需要统一的数据、分子特征和筛选闭环。
2. **数据与特征总览**：展示数据导入、探索、清洗、分子特征、工艺特征和模型输入之间的关系。
3. **分子特征工程**：重点介绍 SMILES/BigSMILES、多组分角色、串接提取、xTB/指纹/描述符、workflow 顺序和特征契约。
4. **工艺特征与模型训练**：说明 PLS 仅在训练流程内拟合、特征选择、缺失值策略、模型训练和可解释性。
5. **高通量筛选**：重点介绍树脂/固化剂候选池、PubChem 扩库、化学规则、配方组合、分批生成、昂贵特征保护、模型输入映射和结果排序。
6. **系统闭环与总结**：强调可复现、可验证、可暂停、可追溯的工程化能力。

## 页级规划

### 开场与背景（1–5）

1. 封面：CFRP 智能预测与虚拟筛选系统。
2. 一句话主张：从原始配方数据到候选配方决策的统一链路。
3. 研究痛点：多组分、稀疏工艺、分子输入与模型输入不一致。
4. 系统定位：预测、解释和筛选的统一平台。
5. 全流程总览：数据 → 特征 → 模型 → 筛选 → 决策。

### 数据与特征工程总览（6–9）

6. 数据进入系统后的处理边界。
7. 数据探索：预览、统计、相关性和图形导出。
8. 原始列、处理列和模型列的关系。
9. 特征工程分层：分子特征、工艺特征、配方特征。

### 分子特征工程重点（10–18）

10. 分子输入类型：SMILES、BigSMILES 和多组分表达。
11. 树脂/固化剂角色分离与来源列选择。
12. 串接提取 workflow：按步骤、角色和顺序合并。
13. 分子特征方法矩阵：xTB、指纹、描述符、构象/力场、图模型接口。
14. xTB 特征提取的计算链路与并行保护。
15. BigSMILES 与复杂分子表达的解析边界。
16. workflow 复现：导入、校验、人工补充流程、锁定。
17. 特征契约：模型指纹、workflow 指纹、目录指纹和最终特征顺序。
18. 常见失败为何会被拦截：角色冲突、列顺序不一致和非数值特征。

### 工艺特征与模型训练（19–23）

19. 稀疏工艺特征的处理策略。
20. PLS 工作流：训练折拟合、转换和防止数据泄漏。
21. 特征选择与目标缺失策略。
22. 多模型训练与输入契约。
23. 预测、适用域和模型解释的输出链路。

### 高通量筛选重点（24–30）

24. 筛选目标：从单分子预测转向配方级候选。
25. 树脂与固化剂候选池：实测库、上传库、PubChem 和虚拟库。
26. PubChem 查询：CID 上限、最终采样、官能团/子结构/工业过滤。
27. 配方设计空间：组分数、配比、PHR、EEW/AHEW 和工艺网格。
28. 分批生成与筛选：边生成边评估、进度反馈、暂停与内存保护。
29. 复用与提取：实测特征复用、唯一分子采样、昂贵特征计算保护。
30. 结果筛选：化学规则、适用域、不确定度、联合评分和候选排序。

### 闭环与总结（31–32）

31. 可追溯闭环：每个结果回到来源、特征流程和模型版本。
32. 总结：把“分子表达—特征—模型—配方”连接成可复现的科研计算系统。

## 视觉设计

- 画布：16:9，安全区域保持统一边距。
- 配色：主色深蓝 `1A237E`，辅助色青绿色 `2A9D8F`，强调色橙色 `E9C46A`，背景使用白色/浅灰；遵循 7:2:1 比例。
- 字体：中文使用 Microsoft YaHei，英文与数字使用 Arial；标题与正文保持至少 2 倍字号对比。
- 视觉语言：科研流程图、分支结构、输入输出链路和少量数据样式；避免密集仪表盘和仿 UI 卡片堆叠。
- 重点页使用深蓝底或大面积留白形成章节对比；分子特征页以青绿色表示特征流，高通量页以橙色标识候选生成与决策节点。

## 内容边界与真实性

- 只使用当前仓库代码、README、CHANGELOG、流程文档和已有系统结构中的事实。
- 不编造样本量、准确率、筛选命中率或性能提升数字。
- 不把 MACCS、xTB、RDKit 描述符等方法混写为同一种特征；明确“训练流程决定模型输入”。
- 不把 PubChem CID 数、候选数上限或工艺网格数量展示为实验结果；只说明其在候选管理中的作用。
- 主动学习模块不在本次 PPT 中展开。

## 制作与质量检查

- 使用 `PPT-master` 的 PptxGenJS 工作流，生成独立的描述性文件名。
- 每页保留页级元数据，便于目录和质量审计。
- 编译前运行 `node scripts/lint.js`。
- 编译后运行 PPTX 审计和文本抽取，检查乱码、缺页和关键术语。
- 渲染全部页面并检查越界、重叠、裁切、标题换行和对比度。
- 只将最终 `.pptx` 放入项目输出目录；中间文件放在仓库外临时工作区，不污染现有业务文件。
