# 超参数优化可靠性设计

**日期：** 2026-08-01
**状态：** 已确认，待编写实施计划
**范围：** 回归模型的 Optuna 超参数优化

## 目标

将现有“单模型、单次随机评估、只按平均 R² 排名”的超参数优化模块升级为可复现、可解释且不泄漏独立测试集的科研基线。

默认评估策略：

1. 连续目标按自适应分位数分层。
2. 先保留独立测试集。
3. Optuna 只在训练部分执行分位数分层 KFold。
4. 最佳 trial 以平均 R² 为主，并使用折间稳定性作为近似同分时的裁决。
5. 独立测试集只在调参完成后评估一次。

## 非目标

本期不实现以下能力：

- 嵌套交叉验证。
- 分类任务调参。
- 多目标 Pareto 优化。
- 多进程、分布式或远程 Optuna worker。
- 配方分组隔离和时间批次隔离。

这些能力应保留为后续扩展点，但不得影响本期默认流程。

## 当前问题

现有 `core/optimizer.py` 和 `app.py` 中的超参优化页面存在以下可靠性问题：

- 默认快速 Holdout 会导致一次随机划分主导 trial 排名。
- KFold 未按连续目标分布分层，极端目标可能集中在个别验证折。
- `study.best_trial` 只按单个目标值选择，忽略折间波动和最差折表现。
- 独立评估按钮会重新随机划分数据，无法保证其与调参过程中的测试边界一致。
- 优化器过早将特征转为 NumPy 数组，难以与训练页的列感知处理和工艺 PLS workflow 严格复用。
- trial 失败被转换为 `-inf`，页面没有汇总失败原因或明确指出“全部 trial 无效”。

## 总体数据流

```text
输入 X、y、训练预处理配置
        |
        v

        |
        v
按连续目标分位数创建分层标签
        |
        v
外层分位数分层切分：训练部分 / 独立测试集
        |
        v
可选：仅对训练部分进行分层采样以满足快速预算
        |
        v
Optuna trial：
  训练部分内的分位数分层 KFold
  每折独立拟合预处理、工艺 PLS 和模型
        |

        |

        |

        |

```

## 核心组件

### 1. `OptimizationEvaluationConfig`

新增可序列化的评估配置，集中保存并校验：

- `test_size`：默认 `0.20`。
- `cv_folds`：默认 `5`。
- `quantile_bins`：默认自动推导。
- `random_state`：默认 `42`。
- `max_samples`：仅影响外层训练部分，不得抽取或改变独立测试集。
- `stability_tolerance`：默认 `0.005` R²。
- `process_pls_config` 与 `use_process_pls`：与训练页使用相同配置。

页面默认展示关键值；高级设置允许用户调整预算、折数、测试集比例和随机种子。

### 2. 目标清理和自适应分层

创建仅处理回归目标的 helper：

1. 将目标转为数值。
2. 删除目标缺失、非数值和无穷值对应的样本。
3. 从候选分箱数开始创建 `qcut` 分位数标签。
4. 当重复边界或每箱样本数不足时逐级减少分箱数。
5. 保证每个分层至少可支撑外层切分及 `cv_folds` 个内层折。
6. 若无法构成有效分层，抛出带样本统计的可读错误，不回退为普通随机 KFold。

默认候选分箱数取 `min(10, max(2, n_samples // (2 * cv_folds)))`，并继续受每箱最小样本数约束。

### 3. 外层测试集与内层 KFold

外层使用 `StratifiedShuffleSplit`，输入是连续目标生成的分层标签。独立测试集的行索引、目标分层摘要、随机种子和切分比例必须保存到结果对象。

内层使用 `StratifiedKFold(shuffle=True, random_state=random_state)`，仅作用于外层训练部分。每个 trial 使用同一内层切分，保证 trial 间公平可比。

快速模式如启用样本上限，必须在外层切分之后，只对训练部分进行分层采样。独立测试集不得因性能预算而缩小、重采样或参与 trial。

### 4. 折内训练一致性

优化器不得在进入 CV 前丢失 DataFrame 列名。每个折必须通过训练页同源的 estimator/pipeline builder 构建：

- 缺失值处理器只在该折训练数据上 `fit`。
- 标准化器只在该折训练数据上 `fit`。
- 已启用的工艺 PLS workflow 只在该折训练数据上 `fit`。
- 验证折、外层测试集和筛选候选只能调用 `transform` 或 `predict`。
- 模型参数由当前 Optuna trial 提供，模型默认参数及随机种子与训练页保持一致。

如果现有 `EnhancedModelTrainer` 无法提供可复用 builder，应新增最小公共入口，禁止在 `optimizer.py` 复制另一套训练前处理逻辑。

### 5. Trial 统计和稳定性选择

每个完成 trial 必须记录到 `user_attrs` 或等价结构：

- `mean_cv_r2`
- `std_cv_r2`
- `min_cv_r2`
- `fold_scores`
- `completed_folds`
- `failure_reason`（如有）

Optuna 的剪枝报告使用当前已完成折的平均 R²。剪枝、失败和完成状态需要分别统计。

最佳 trial 的选择规则：

1. 排除 `PRUNED`、`FAIL` 以及包含无效折分数的 trial。
2. 找到最高 `mean_cv_r2`。
3. 取与最高均值相差不超过 `stability_tolerance` 的候选。
4. 在候选中依次选择 `std_cv_r2` 更低、`min_cv_r2` 更高、trial 编号更小的组合。

这一定义保持“平均 R² 优先”，同时避免为极小的偶然分差牺牲折间稳定性。

### 6. 最终报告

选择最佳 trial 后，用最佳参数在外层完整训练部分重新拟合一次，并对保留测试集仅预测一次。结果对象至少包含：

- 模型名和最佳参数。
- 内层 CV 平均 R²、标准差、最差折和逐折 R²。
- 独立测试集 R²、RMSE、MAE。
- 训练/测试性能差距。
- 切分配置、随机种子、有效样本数和样本索引摘要。
- trial 总数、完成数、剪枝数、失败数及失败原因摘要。
- 特征列顺序和工艺 PLS workflow 指纹（启用时）。

页面刷新后通过 `st.session_state` 保留结构化结果，不重新运行优化。

## 页面设计

### 优化前检查

在“开始优化”按钮前展示：

- 原始样本数、有效目标样本数和移除数量。
- 目标分布概览。
- 推荐/实际分箱数。
- 外层训练集和独立测试集规模。
- 内层折数。
- 当前模型、随机种子和预算。

若无法创建有效分层、样本不足、目标非数值或模型不可用，禁用按钮并展示修复建议。

### 可靠性设置

默认模式固定为“可信优化基线”，界面可调整：

- 独立测试集比例。
- 内层折数。
- 随机种子。
- 样本预算。
- trial 预算和超时预算。
- 早期剪枝开关。

现有快速 Holdout 改为明确标注的“探索模式”，不再作为默认科研评估方式；探索模式生成的分数必须带“不可作为最终泛化报告”的提示。

### 运行进度

进度面板显示：

- 已完成、剪枝和失败 trial 数。
- 当前稳定性最佳 trial 的平均 R² 与标准差。
- 已用时间与预计剩余时间。
- 当前阶段：数据检查、外层切分、内层优化或独立测试评估。

trial 真正结束、剪枝或失败后才更新计数和进度。

### 结果呈现

结果区域分为两个固定区块：

1. **内层交叉验证结果**：参数选择依据，展示平均 R²、标准差、最差折和逐折分数。
2. **独立测试集结果**：明确标注为“未参与调参”，展示 R²、RMSE、MAE 和泛化差距。

同时显示最佳参数、trial 状态汇总、失败原因摘要、可下载结果表，以及“使用最佳参数训练模型”入口。

该训练入口只复用最佳参数。正式建模使用全数据重新拟合，独立测试指标保留为调参报告，不伪装为全数据训练指标。

## 错误处理

- 目标含缺失、非数值或无穷值：优化前移除并报告数量；无有效样本时阻断。
- 样本数不足或分位箱无法满足折数：阻断并说明需要减少折数、降低分箱或补充数据。
- 模型依赖缺失：开始前阻断并显示依赖名称。
- 单个 trial 失败：保留失败状态和简化错误原因，继续其余 trial。
- 全部 trial 无效：不访问 `study.best_params`，改为显示失败汇总及下一步建议。
- 独立测试评估失败：保留内层结果，单独报告最终评估失败原因，不丢弃已完成 study。

## 测试与验收

新增或扩展 pytest 用例，验证：

1. 连续目标能稳定生成满足折数约束的分位数分层。
2. 独立测试集行索引不会进入任何 Optuna trial 的训练或验证折。
3. 缺失值处理、标准化和工艺 PLS 仅在每个训练折拟合。
4. 相近平均 R² 时，较低标准差的 trial 被选为最佳。
5. 分层样本不足时返回可读错误，不静默回退到随机 KFold。
6. 单个失败 trial 被正确记录，所有 trial 失败时返回可读结果。
7. 最终独立测试指标只在最佳参数确定后计算一次。
8. 页面刷新后能读取已保存的结构化优化结果，不重新执行 study。

## 迁移与兼容性

- 保留当前 `HyperparameterOptimizer` 名称。
- 对现有页面调用提供兼容入口，逐步迁移为结构化结果对象。
- 当前普通 KFold/Holdout 模式保留为“探索模式”，但不作为默认值。
- 未启用工艺 PLS 的模型保持现有输入处理路径；启用时必须在优化与训练中使用相同 workflow 指纹。
- 不修改已经训练完成的模型 artifact，也不重写历史优化记录。
